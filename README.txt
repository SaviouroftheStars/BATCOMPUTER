GITHUB PAGES
------------
1. Create a GitHub account.
2. Create a PUBLIC repository, e.g. batcomputer.
3. Upload index.html, batcomputer.css and batcomputer.js to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch.
5. Choose main and /(root), then Save.
6. GitHub will provide the public Pages address.

Do not rename the three files unless you also update the references in index.html.
